# rust-zerotier

A Rust port of an educational L2 VPN — a virtual switch and virtual port that
mimics the behaviour of ZeroTier, with a minimalist black-and-white control
panel GUI.

> Inspired by [`for-tristan/build-your-own-zerotier`](https://github.com/for-tristan/build-your-own-zerotier),
> an educational C + Python implementation of the same concept.

## Status

Under active development. See the commit history for build progress.
